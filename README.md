# ReminderMuslim

ReminderMuslim ialah Progressive Web App (PWA) ringkas untuk membantu pengguna mengakses kandungan Islam harian melalui iPhone atau browser.

## Live App

https://oobp12.github.io/ReminderMuslimWeb/

## Ciri Utama

- Utama — petikan Islamik harian
- Kategori — semak petikan mengikut tema
- Al-Quran & Zikir
  - Surah
  - Zikir Pagi
  - Zikir Petang
  - Tasbih Digital
- Waktu Solat
- Panduan Solat
- Kegemaran
- Tetapan saiz teks
- Mod Gelap
- Sokongan BM / English
- Offline mode melalui Service Worker
- PWA — boleh ditambah ke iPhone Home Screen

## Cara Pasang di iPhone

1. Buka link ReminderMuslim menggunakan Safari.
2. Tekan butang Share.
3. Pilih **Add to Home Screen**.
4. Aktifkan **Open as Web App** jika pilihan itu dipaparkan.
5. Tekan **Add**.

Selepas itu, ReminderMuslim boleh dibuka terus daripada Home Screen seperti sebuah aplikasi.

## Offline Mode

Selepas aplikasi dibuka sekurang-kurangnya sekali dengan internet, kandungan asas yang telah dicache boleh dibuka semula ketika offline.

Waktu solat yang memerlukan data rangkaian/lokasi mungkin menggunakan data terakhir yang disimpan atau memaparkan status bahawa data semasa tidak tersedia.

## Waktu Solat

Waktu solat menggunakan data pengiraan berasaskan lokasi. Ia hendaklah dianggap sebagai rujukan dan bukan pengganti jadual rasmi pihak berautoriti tempatan.

## Nota Kandungan Agama

Kandungan zikir, transliterasi, maksud, niat dan panduan solat hendaklah disemak dengan sumber agama yang dipercayai atau individu berautoriti sebelum digunakan untuk penerbitan umum.

## Privasi

ReminderMuslim tidak memerlukan akaun pengguna.

Data seperti kegemaran, saiz teks, mod gelap, tetapan bahasa dan kiraan tasbih disimpan secara lokal pada peranti/browser pengguna.

Jika pengguna membenarkan akses lokasi, lokasi digunakan untuk mendapatkan waktu solat dan tidak dimaksudkan untuk disimpan sebagai profil pengguna.
